# Timing validation snapshot

This directory stores **derived, pseudonymous timing features**, not raw PGNs,
player names, moves, or private data. `records.jsonl` is generated by
`tools/timing_classifier_validation.py`; `source-manifest.json` pins the public
inputs and their hashes; `report.json` is deterministic for the committed
configuration and random seed.

The source games are Lichess rated standard games. Lichess publishes database
exports under CC0. A `BOT` title is affirmative Bot API metadata. Absence of
that title is only an **unmarked/human-proxy** label and must not be treated as
verified human identity.

See [`docs/timing-classifier-validation.md`](../../docs/timing-classifier-validation.md)
for acquisition, reproduction, statistical protocol, and limitations.
