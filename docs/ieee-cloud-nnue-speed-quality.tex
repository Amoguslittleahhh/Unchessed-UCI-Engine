\begin{abstract}
We specify the exact A100 training stack that Unchessed will run in the cloud: GPU-resident shards, batch 131072, TF32, bfloat16 autocast, fused Adam, cuDNN benchmark, early-stop on val-MAE, best-checkpoint export, and a fail-closed preflight that refuses to start unless Adaptive/persona stays on, UnarchitecturedHint stays off, and the operator types \texttt{GO\_CLOUD=I\_ACCEPT\_SPRT\_GATES}. Speed knobs do not change the WDL$^{2.5}$ loss or the feature scheme. Quality is defined as SPRT, not as a small printed val-MAE. This paper records why each choice is the fast path that still matches the shipped recipe.
\end{abstract}
\begin{IEEEkeywords}
NNUE, A100, TF32, mixed precision, SPRT, UCI Adaptive, cloud preflight
\end{IEEEkeywords}

\section{Introduction}
Billing on an A100 is wall-clock. The previous cloud launcher still said ``v3'', exported last-checkpoint nets, and could start without a go token. This revision makes the launcher v4, fail-closed, persona-on, and as fast as the hardware allows without touching the loss.

We do not claim 100\% Elo. We claim 100\% \emph{pipeline certainty}: a billed run cannot start unless preflight passes, and Adaptive cannot be turned off by that run.

\section{Non-negotiable quality}
\begin{itemize}
\item Loss: $|\sigma(\mathrm{raw})-t|^{2.5}$, $t=0.7\sigma(\mathrm{cp}/400)+0.3(\mathrm{wdl}/2)$ --- Stockfish nnue-pytorch, already validated here.
\item Features: HalfKAv2\_hm + factorization; export UNCHNNUE v4.
\item Cap 15 epochs, patience 3, $\Delta=0.1$\,cp, \textbf{best} checkpoint.
\item Adaptive default true. Hint default false.
\item Promote only after SPRT vs \texttt{unchessed-nnue.bin} at $10+0.1$, Adaptive on.
\end{itemize}

\section{Speed choices}
\paragraph{GPU-resident data.} One host$\to$device copy of the 104-byte records. Shuffle is a \texttt{randperm} on device. Removes the PCIe bottleneck that made CPU training the slow path.
\paragraph{Batch 131072.} Production A100 size in \texttt{full\_pipeline\_cloud.sh}. The net is tiny (export table $22528\times256$); occupancy, not model size, is the limit.
\paragraph{TF32 tensor cores.} Default on Ampere. Matmul/conv use 10-bit mantissa; EmbeddingBag integer indices are unchanged. Elo-relevant weights still export f32.
\paragraph{bf16 autocast.} Forward+loss in bfloat16; Adam stays f32 master weights. No GradScaler (bf16 exponent matches fp32). Opt-out \texttt{USE\_AMP=0} if a future kernel miscasts indices --- indices are int64 and sit outside autocast.
\paragraph{Fused Adam.} One CUDA kernel for the moment update. Fallback if the installed torch lacks \texttt{fused=True}.
\paragraph{cuDNN benchmark.} Harmless for this graph; kept for the Linear head.
\paragraph{torch.compile off by default.} EmbeddingBag + dynamic nnz has compiled poorly in the field. Opt-in only.
\paragraph{zero\_grad(set\_to\_none=True).} Avoids zeroing 11M+ embedding rows every step.
\paragraph{Early stop.} The 100-epoch v3 run paid for 35 useless epochs after the minimum. Patience 3 is the cheapest quality win.

\section{Fail-closed preflight}
\texttt{tools/nnue\_cloud\_runtime.py} blocks if persona is off, hint is on, records $<1000$ or $>5\cdot10^8$, or the go token is missing. \texttt{scripts/nnue-pipeline/cloud\_train\_v4.sh} exports the same token requirement. An empty \texttt{GO\_CLOUD} in the monthly pipeline now fails training instead of silently starting v3.

\section{Persona}
Personas live in \texttt{adapt.rs} and read search eval, not the trainer. Training a stronger net with Adaptive left at its UCI default is the configuration the SPRT must use. Turning Adaptive off for ``cleaner Elo'' is a different experiment and is not this launcher.

\section{What this does not claim}
Sub-20\,cp val-MAE on HCE 5k-node labels remains unreachable (Bayes floor $\approx56$\,cp). Speed knobs do not lower that floor. Cloud 178M is still gated on a local 108M best-ckpt SPRT for \emph{Elo}; this paper only makes that run fast and un-sabotageable if someone accepts the gate.

\section{Reproduction}
\begin{verbatim}
GO_CLOUD=I_ACCEPT_SPRT_GATES DEVICE=cuda \
  BATCH_SIZE=131072 \
  scripts/nnue-pipeline/cloud_train_v4.sh \
  out.bin shard*.bin
\end{verbatim}
