# Apex v1 naming candidate — experimental

> **Experimental naming record.** This name is not canonical. The current
> architecture is [Unarchitectured v1](unarchitectured-v1.md).

Apex v1 was a short-lived naming reset applied to the architecture developed
under Hydra v1-v5. It is retained only so historical commits and calculated
reports remain interpretable.

No model or package using `UNCHAPX1` was trained or released. The canonical
runtime magic is now `UNARCHV1`; no compatibility migration is required.

See:

- `config/architecture_registry.json`
- `config/unarchitectured_v1.json`
- `docs/unarchitectured-v1.md`
- `benchmarks/unarchitectured-v1/`
