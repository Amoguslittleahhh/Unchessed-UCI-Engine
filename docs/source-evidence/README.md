# Reference-only source evidence

This directory intentionally contains **no Stockfish source code, network weights, copied feature tables, or implementation fragments**.

Stockfish was studied only through public documentation, black-box UCI measurements, and an externally supplied reference archive held outside the repository. The supplied archive is not a dependency and is not committed here. Its checksum and provenance are recorded in `docs/stockfish-reference-provenance.md`.

All Unchessed implementation code is independently authored. The reference materials may inform research questions, but they must not be copied into the engine.
